# sankler.com.br

Site de Sankler Bergman: projetos, forma de trabalhar e contato, em português (`/`) e inglês (`/en/`).

- HTML e CSS puros, sem fontes externas nem cookies. O único script é o do Cloudflare Web Analytics, que conta as visitas.
- O desenho segue um talão de ordem de serviço: o azul da marca imprime a grade e os rótulos, e o conteúdo entra em branco sobre o preto. O site é sempre escuro.
- Marca Sankler (símbolo, logo, ícones e guia de uso) em `assets/brand/`.
- Fonte Archivo (licença OFL, em `assets/fonts/OFL.txt`), servida pelo próprio site.
- Publicado pelo GitHub Pages no domínio `sankler.com.br` (arquivo `CNAME`).
- As capturas usam dados fictícios. O código dos sistemas privados não está aqui.
